## 🔧 ТЕХНИЧЕСКИЕ ДЕТАЛИ

### Текущая структура Subscription
```python
- status: "active" (только один статус)
- provider: "stripe" | "apple" | "google" | None
- external_id: ID в платежной системе
- current_period_end: дата окончания периода
- is_trial: boolean
```

### Что нужно добавить
```python
- cancel_at_period_end: boolean (отменена, но активна до конца периода)
- cancelled_at: datetime (когда была отменена)
- reactivated_at: datetime (когда была возобновлена)
- last_transaction_id: int (FK к Transaction)
```

### Новая модель Transaction
```python
class Transaction(Base):
    id: int
    subscription_id: int (FK)
    amount: float
    currency: str
    payment_method: str  # "card", "apple_pay", "google_pay", "erl_pay"
    status: str  # "pending", "succeeded", "failed", "refunded"
    transaction_date: datetime
    external_transaction_id: str  # ID в платежной системе
    created_at: datetime
```
