## 🌐 API Endpoints для фронтенда

### Получить список доступных типов
```
GET /specialist-profiles/types
```
Ответ:
```json
{
  "categories": {
    "beauty": {
      "name": "Красота",
      "types": ["massage", "cosmetologist", ...]
    },
    ...
  }
}
```

### Получить свой профиль
```
GET /specialist-profiles/me
```

### Обновить свой профиль
```
PUT /specialist-profiles/me
Body: {
  "specialization": "...",
  "experience_years": 5,
  ...
}
```

### Получить профиль специалиста (публичный)
```
GET /specialist-profiles/users/{user_id}
```

### Список специалистов с фильтрами
```
GET /specialist-profiles?specialist_category=beauty&is_verified=verified
```
