# Где найти разделение специалистов

## ✅ Что было реализовано:

### 1. **Регистрация нового специалиста** 
📍 **Место:** Страница регистрации (`/register`)

Когда пользователь выбирает роль "specialist" при регистрации, появляется поле **"Specialist Type"** (Тип специалиста) с выпадающим списком, где можно выбрать:
- Массажист
- Косметолог
- Барбер
- Парикмахер
- Эстетист
- Мастер маникюра/педикюра
- Мастер по ресницам и бровям
- Визажист
- Физиотерапевт
- Нутрициолог
- И многие другие типы (всего 25+ типов в 3 категориях: Beauty, Wellness, Healthcare)

### 2. **Страница профиля специалиста**
📍 **Место:** `/profile` (доступна только для специалистов)

В навигационном меню (верхняя панель) для специалистов появляется ссылка **"Profile"** (👤 Profile).

На этой странице специалист может:
- Просмотреть свой тип специалиста
- Просмотреть категорию (Beauty / Wellness / Healthcare)
- Заполнить расширенную информацию:
  - Специализация
  - Опыт работы (лет)
  - Образование
  - Сертификаты
  - Название бизнеса
  - Тип бизнеса
  - Адрес
  - Описание
  - Языки

### 3. **Валидация для healthcare специалистов**
📍 **Место:** Форма создания/редактирования клиента

Для специалистов из категории Healthcare (врачи, стоматологи и т.д.) при создании клиента становятся **обязательными** поля:
- Аллергии (allergies)
- Хронические заболевания (chronic_diseases)

И отображается предупреждение о необходимости заполнения этих полей.

## 🔍 Как проверить:

1. **Зарегистрировать нового специалиста:**
   - Перейдите на `/register`
   - Выберите роль "Specialist"
   - Появится поле "Specialist Type" с выбором типа

2. **Посмотреть профиль существующего специалиста:**
   - Войдите как специалист
   - В верхней навигации нажмите "Profile" (👤 Profile)
   - Увидите страницу с информацией о профиле специалиста

3. **Проверить валидацию для healthcare:**
   - Войдите как специалист из категории Healthcare (например, врач)
   - Создайте нового клиента
   - Увидите предупреждение и обязательные поля для аллергий и заболеваний

## 📊 База данных:

- В таблице `users` добавлено поле `specialist_type` (может быть NULL)
- Создана таблица `specialist_profiles` с расширенной информацией
- API endpoints: `/specialist-profiles/*` для работы с профилями

## 🌐 API Endpoints:

- `GET /specialist-profiles/me` - получить свой профиль
- `PUT /specialist-profiles/me` - обновить свой профиль
- `GET /specialist-profiles/types` - получить список всех типов специалистов
- `GET /specialist-profiles/users/{user_id}` - получить профиль специалиста по ID пользователя
