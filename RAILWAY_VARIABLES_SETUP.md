# 🔧 Настройка переменных окружения в Railway

## 📍 Где добавлять переменные

Вы находитесь в правильном месте! Но нужно добавить **свои переменные**, а не только использовать системные.

---

## ✅ Шаг 1: Добавьте переменные окружения

### В текущем окне "Variables":

1. **Найдите кнопку "New Variable"** в правом верхнем углу
   - Она должна быть видна в разделе "Service Variables"

2. **Или используйте "Raw Editor":**
   - Нажмите **"Raw Editor"** (вверху страницы)
   - Вы увидите формат для вставки переменных

---

## 📝 Шаг 2: Добавьте необходимые переменные

Добавьте следующие переменные (по одной):

### 1. JWT Secret (обязательно)

**Кнопка "New Variable":**
- **Key**: `JWT_SECRET`
- **Value**: придумайте длинный случайный ключ (минимум 32 символа)
  - Пример: `my-super-secret-jwt-key-for-xtrix-2024-minimum-32-chars`
- Нажмите **"Add"**

### 2. Environment (обязательно)

**Кнопка "New Variable":**
- **Key**: `ENVIRONMENT`
- **Value**: `production`
- Нажмите **"Add"**

### 3. CORS Origins (для работы с фронтендом на Vercel)

**Кнопка "New Variable":**
- **Key**: `CORS_ORIGINS`
- **Value**: `https://ваш-фронтенд.vercel.app,https://ваш-фронтенд-*.vercel.app`
  - Замените `ваш-фронтенд` на реальный URL вашего фронтенда на Vercel
  - Пример: `https://xtrix-frontend.vercel.app,https://xtrix-frontend-*.vercel.app`
- Нажмите **"Add"**

### 4. DATABASE_URL (автоматически, если добавили PostgreSQL)

Если вы уже добавили PostgreSQL базу данных:
- `DATABASE_URL` **уже должен быть автоматически добавлен** Railway
- Проверьте в списке переменных - он должен быть там
- Если его нет - см. "Добавление PostgreSQL" ниже

---

## 🗄️ Шаг 3: Добавьте PostgreSQL (если еще не добавили)

Если базы данных еще нет:

1. **Вернитесь на главную страницу проекта** (нажмите на название проекта)

2. **Нажмите "+ New"** (или "+" вверху)

3. **Выберите "Database" → "Add PostgreSQL"**

4. **Railway автоматически:**
   - Создаст базу данных
   - Добавит переменную `DATABASE_URL` в ваш сервис
   - Подключит её автоматически

5. **Проверьте:**
   - Вернитесь в **Variables**
   - Должна появиться переменная `DATABASE_URL`

---

## 📋 Полный список переменных для добавления

### Обязательные:
```
JWT_SECRET=ваш-длинный-секретный-ключ-минимум-32-символа
ENVIRONMENT=production
DATABASE_URL=postgresql://... (добавляется автоматически при создании PostgreSQL)
```

### Для работы с фронтендом на Vercel:
```
CORS_ORIGINS=https://ваш-фронтенд.vercel.app,https://ваш-фронтенд-*.vercel.app
```

### Опциональные (если используете):
```
REDIS_URL=redis://... (если добавляете Redis)
SMTP_USER=... (если используете email)
SMTP_PASSWORD=...
```

---

## 🔄 Шаг 4: Перезапустите сервис

После добавления переменных:

1. **Перейдите в раздел "Deployments"** (в меню слева)
2. Нажмите **"..."** (три точки) у последнего деплоя
3. Выберите **"Redeploy"**
4. Или Railway может перезапустить автоматически

---

## ✅ Проверка

После добавления переменных и перезапуска:

1. **Перейдите в раздел "Deployments"**
2. **Найдите последний деплой**
3. **Нажмите на него** → увидите логи
4. **Проверьте, что нет ошибок**

---

## 🌐 Получить URL бэкенда

1. В разделе вашего сервиса (не проекта, а конкретного сервиса)
2. Во вкладке **"Settings"**
3. Найдите **"Domains"** или **"Networking"**
4. Там будет URL типа: `https://ваш-проект.up.railway.app`

Или:

1. Перейдите в **"Deployments"**
2. Нажмите на последний успешный деплой
3. В логах или в информации о деплое будет показан URL

---

## 💡 Альтернативный способ: Raw Editor

Если не видите кнопку "New Variable":

1. Нажмите **"Raw Editor"** (вверху страницы Variables)
2. Увидите формат вроде:
   ```
   KEY1=value1
   KEY2=value2
   ```
3. Добавьте свои переменные:
   ```
   JWT_SECRET=ваш-секретный-ключ
   ENVIRONMENT=production
   CORS_ORIGINS=https://ваш-фронтенд.vercel.app
   ```
4. Нажмите **"Save"** или **"Update"**

---

## 🆘 Если не видите кнопку "New Variable"

Возможные причины:
1. **Недостаточно прав** - убедитесь, что вы владелец проекта
2. **Неправильный раздел** - убедитесь, что вы в "Service Variables", а не "Project Variables"
3. **Попробуйте обновить страницу** (F5)

---

## 📝 Важно

- Переменные чувствительны к регистру: `JWT_SECRET` ≠ `jwt_secret`
- Не используйте пробелы в значениях без кавычек
- После изменения переменных нужно перезапустить сервис
