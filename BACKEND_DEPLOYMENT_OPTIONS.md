# 🚀 Варианты развертывания бэкенда

## ❌ Почему localhost:8000 не работает с Vercel

**Проблема:** 
- `localhost` доступен только на вашем компьютере
- Когда кто-то открывает сайт на Vercel, браузер пытается обратиться к `localhost:8000` на их компьютере
- У них нет вашего бэкенда, поэтому возникает Network Error

**Решение:** Нужно развернуть бэкенд на публичном сервере

---

## ✅ Вариант 1: Railway (Рекомендуется - самый простой)

Railway автоматически определяет Python проекты и поддерживает PostgreSQL.

### Шаги:

1. **Зарегистрируйтесь на Railway:**
   - Откройте: https://railway.app
   - Войдите через GitHub

2. **Создайте проект:**
   - Нажмите **"New Project"**
   - Выберите **"Deploy from GitHub repo"**
   - Выберите ваш репозиторий

3. **Добавьте базу данных:**
   - Нажмите **"+ New"** → **"Database"** → **"Add PostgreSQL"**
   - Railway автоматически создаст переменную `DATABASE_URL`

4. **Настройте переменные окружения:**
   - В настройках проекта → **Variables**
   - Добавьте необходимые переменные:
     ```
     JWT_SECRET=ваш-секретный-ключ-минимум-32-символа
     ENVIRONMENT=production
     CORS_ORIGINS=https://ваш-фронтенд.vercel.app,https://ваш-фронтенд-*.vercel.app
     ```
   - `DATABASE_URL` уже добавлен автоматически

5. **Настройте деплой:**
   - В настройках → **Deploy** → установите:
     - **Root Directory**: оставьте пустым (корень проекта)
     - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`

6. **Дождитесь деплоя:**
   - Railway автоматически определит Python проект
   - После деплоя скопируйте URL (например: `https://ваш-проект.up.railway.app`)

7. **Примените миграции:**
   - В терминале Railway запустите: `alembic upgrade head`

8. **Используйте URL в фронтенде:**
   - В Vercel (фронтенд) добавьте переменную:
     ```
     VITE_API_BASE_URL=https://ваш-проект.up.railway.app
     ```

## ✅ Вариант 2: Render (Бесплатный тариф)

### Шаги:

1. **Зарегистрируйтесь:** https://render.com

2. **Создайте Web Service:**
   - **New** → **Web Service**
   - Подключите GitHub репозиторий

3. **Настройки:**
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`

4. **Добавьте PostgreSQL:**
   - **New** → **PostgreSQL**
   - В настройках Web Service добавьте переменную:
     ```
     DATABASE_URL=<скопируйте из PostgreSQL сервиса>
     ```

5. **Добавьте остальные переменные:**
   ```
   JWT_SECRET=ваш-секретный-ключ
   ENVIRONMENT=production
   CORS_ORIGINS=https://ваш-фронтенд.vercel.app
   ```

6. **Дождитесь деплоя** и используйте URL в фронтенде

## ✅ Вариант 3: Временное решение - ngrok (ТОЛЬКО для тестирования)

⚠️ **Внимание:** Это только для быстрого тестирования! Не для продакшена!

### Установка и использование:

1. **Установите ngrok:**
   - Скачайте: https://ngrok.com/download
   - Или через npm: `npm install -g ngrok`

2. **Зарегистрируйтесь на ngrok:**
   - Получите бесплатный токен на https://ngrok.com

3. **Запустите туннель:**
   ```powershell
   ngrok http 8000
   ```

4. **Скопируйте URL:**
   - Вы увидите что-то вроде: `https://abc123.ngrok.io`

5. **Используйте в Vercel:**
   - В Vercel добавьте переменную:
     ```
     VITE_API_BASE_URL=https://abc123.ngrok.io
     ```
   - ⚠️ **Проблема:** URL меняется при каждом перезапуске ngrok

6. **Важно:** 
   - Ngrok работает только пока запущен на вашем компьютере
   - Бесплатная версия ограничена
   - Не подходит для демонстрации другим людям

### Проблемы:
- Нужно переделать под serverless функции
- База данных должна быть внешней (Railway/Render/etc)

## 📝 После развертывания бэкенда

1. **Скопируйте URL бэкенда** (например: `https://ваш-проект.up.railway.app`)

2. **В Vercel (фронтенд):**
   - Settings → Environment Variables
   - Добавьте: `VITE_API_BASE_URL=https://ваш-проект.up.railway.app`
   - Переразверните фронтенд

3. **На бэкенде:**
   - Добавьте CORS:
     ```
     CORS_ORIGINS=https://ваш-фронтенд.vercel.app,https://ваш-фронтенд-*.vercel.app
     ```

4. **Готово!** Теперь всё должно работать
