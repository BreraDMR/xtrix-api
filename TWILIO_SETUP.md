# Настройка Twilio для SMS восстановления пароля

## Что такое Twilio?

Twilio - это сервис для отправки SMS сообщений на любые номера телефонов по всему миру.

## Преимущества для восстановления пароля:

- ✅ Можно отправлять SMS на **любые** номера автоматически
- ✅ Не нужно ничего верифицировать заранее
- ✅ Работает в любых странах
- ✅ Надежная доставка

## Шаг 1: Регистрация в Twilio

1. Откройте https://www.twilio.com
2. Нажмите **Sign Up** (Регистрация)
3. Заполните форму регистрации
4. Подтвердите email и телефон
5. **Важно**: При регистрации получите бесплатные $15.50 для тестирования

## Шаг 2: Получение учетных данных

После регистрации вы получите:

1. **Account SID** (начинается с `AC...`)
   - Находится в Dashboard → Account Info
   
2. **Auth Token**
   - Находится в Dashboard → Account Info
   - ⚠️ **Важно**: Показывается только один раз, сохраните его!

3. **Phone Number** (номер для отправки)
   - Нажмите **Phone Numbers** → **Buy a number**
   - Выберите страну и тип номера (SMS)
   - Первый номер стоит $1 (используйте бесплатные деньги)

## Шаг 3: Добавление переменных в Railway

Перейдите в Railway → ваш проект → Variables и добавьте:

| Переменная | Значение | Пример |
|-----------|----------|--------|
| `TWILIO_SID` | Account SID из Twilio Dashboard | `ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx` |
| `TWILIO_TOKEN` | Auth Token из Twilio Dashboard | `your_auth_token_here` |
| `TWILIO_FROM` | Номер телефона для отправки (с +) | `+1234567890` |

**Формат `TWILIO_FROM`:** Обязательно с `+` и кодом страны, например:
- `+420792686237` (Чехия)
- `+1234567890` (США)
- `+79123456789` (Россия)

## Шаг 4: Проверка работы

1. Railway автоматически перезапустит сервис
2. Проверьте логи Railway - должны быть сообщения об успешной отправке
3. Попробуйте восстановить пароль через форму "Forgot password?"
4. Выберите вариант "по номеру телефона"
5. Проверьте SMS на своем телефоне

## Стоимость

### Бесплатно при регистрации:
- $15.50 для тестирования
- Этого хватит на ~2,000 SMS

### Тарифы:
- **SMS в США**: ~$0.0075 за SMS
- **SMS в другие страны**: зависит от страны
- **Номер телефона**: $1/месяц
- Полный прайс: https://www.twilio.com/pricing

### Пример расчета:
- 100 SMS/месяц = ~$0.75
- Номер телефона = $1
- **Итого**: ~$1.75/месяц за 100 SMS

## Troubleshooting

### SMS не приходит:
1. Проверьте логи Railway на наличие ошибок
2. Проверьте, что `TWILIO_SID`, `TWILIO_TOKEN`, `TWILIO_FROM` правильно установлены
3. Проверьте баланс в Twilio Dashboard (нужно > $0)
4. Проверьте формат номера телефона (должен быть с + и кодом страны)

### Ошибка "Authentication failed":
- Проверьте правильность `TWILIO_SID` и `TWILIO_TOKEN`

### Ошибка "Invalid phone number":
- Проверьте формат `TWILIO_FROM` (должен быть с + и кодом страны)
- Пример: `+420792686237` ✅ (правильно)
- Пример: `420792686237` ❌ (неправильно, нет +)

### "Insufficient funds":
- Пополните баланс в Twilio Dashboard
- Или используйте бесплатные деньги при регистрации

## Что будет, если Twilio не настроен?

Если переменные `TWILIO_SID`, `TWILIO_TOKEN`, `TWILIO_FROM` не установлены:

- ✅ Код восстановления будет сгенерирован
- ✅ Код будет сохранен в базе данных
- ❌ SMS не будет отправлена
- ✅ Код будет залогирован в Railway (для тестирования)
- ⚠️ Пользователь не получит SMS (только для разработки!)

## Важно для продакшена:

Для продакшена **обязательно** настройте Twilio, чтобы пользователи могли получать SMS с кодами восстановления пароля.
