# 🔧 Исправление Network Error на Vercel

## Проблема
При попытке логина или регистрации на развернутом сайте Vercel возникает "Network Error".

## Причины
1. Не установлена переменная окружения `VITE_API_BASE_URL`
2. Бэкенд недоступен (используется localhost)
3. CORS не настроен на бэкенде для домена Vercel

---

## ✅ Решение по шагам

### Шаг 1: Проверьте/установите переменную окружения в Vercel

1. Откройте ваш проект в Vercel
2. Перейдите в **Settings** → **Environment Variables**
3. Проверьте, есть ли переменная `VITE_API_BASE_URL`
4. Если её нет:
   - Нажмите **"Add New"**
   - **Key**: `VITE_API_BASE_URL`
   - **Value**: URL вашего бэкенда (например: `https://your-backend.vercel.app`)
   - Выберите все окружения: Production, Preview, Development
   - Нажмите **"Save"**

### Шаг 2: Переразверните проект

**Важно!** После изменения переменных окружения нужно переразвернуть:

1. Перейдите в **Deployments**
2. Найдите последний деплой
3. Нажмите **"..."** (три точки) → **"Redeploy"**
4. Подождите завершения деплоя

### Шаг 3: Убедитесь, что бэкенд доступен

**Если бэкенд еще не развернут:**
- Разверните бэкенд на Railway, Render или другом сервисе
- Скопируйте URL бэкенда (например: `https://xtrix-backend.up.railway.app`)
- Используйте этот URL в переменной `VITE_API_BASE_URL`
- 📖 **Подробная инструкция:** см. файл `BACKEND_DEPLOYMENT_OPTIONS.md`

**Если используете localhost:8000:**
- ❌ Это **не будет работать** на Vercel!
- Нужен реальный публичный URL бэкенда
- `localhost` доступен только на вашем компьютере, а пользователи сайта на Vercel не могут к нему подключиться

### Шаг 4: Настройте CORS на бэкенде

На бэкенде нужно разрешить запросы с вашего домена Vercel:

**Если бэкенд на Vercel:**
1. Перейдите в настройки бэкенд-проекта на Vercel
2. **Settings** → **Environment Variables**
3. Добавьте/измените:
   - **Key**: `CORS_ORIGINS`
   - **Value**: `https://ваш-фронтенд.vercel.app,https://ваш-фронтенд-*.vercel.app`
   - Пример: `https://xtrix-frontend.vercel.app,https://xtrix-frontend-*.vercel.app`
4. Добавьте/измените:
   - **Key**: `ENVIRONMENT`
   - **Value**: `production`
5. Переразверните бэкенд

**Если бэкенд локально или на другом сервисе:**
1. Найдите файл `.env` бэкенда
2. Добавьте/измените:
   ```
   CORS_ORIGINS=https://ваш-фронтенд.vercel.app,https://ваш-фронтенд-*.vercel.app
   ENVIRONMENT=production
   ```
3. Перезапустите бэкенд

---

## 🔍 Как проверить, что все работает

1. **Откройте развернутый сайт на Vercel**
2. **Откройте консоль браузера** (F12)
3. **Перейдите на вкладку Network**
4. **Попробуйте войти**
5. **Проверьте запросы:**
   - Должен быть запрос на ваш бэкенд URL
   - Если запрос идет на `/api` - переменная `VITE_API_BASE_URL` не установлена
   - Если запрос идет на `localhost:8000` - переменная установлена неправильно
   - Если запрос блокируется CORS - нужно настроить CORS на бэкенде

---

## 📝 Пример правильной настройки

**В Vercel (фронтенд):**
```
VITE_API_BASE_URL = https://xtrix-backend.vercel.app
```

**В Vercel или .env (бэкенд):**
```
CORS_ORIGINS = https://xtrix-frontend.vercel.app,https://xtrix-frontend-*.vercel.app
ENVIRONMENT = production
```

## ❓ Частые ошибки

### "Network Error" или "Failed to fetch"
- ✅ Проверьте `VITE_API_BASE_URL` в Vercel
- ✅ Убедитесь, что бэкенд доступен по указанному URL
- ✅ Проверьте CORS настройки

### "CORS policy: No 'Access-Control-Allow-Origin' header"
- ✅ Добавьте домен Vercel в `CORS_ORIGINS` на бэкенде
- ✅ Убедитесь, что `ENVIRONMENT=production` на бэкенде
- ✅ Перезапустите бэкенд после изменения CORS

### "404 Not Found" при запросе к API
- ✅ Проверьте, что URL бэкенда правильный
- ✅ Убедитесь, что бэкенд развернут и работает
- ✅ Проверьте, что путь к API правильный (не должно быть `/api` в начале)
