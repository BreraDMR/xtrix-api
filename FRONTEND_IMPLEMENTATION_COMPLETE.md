- Отображается в меню навигации только для специалистов

## 📝 Технические детали

### API Endpoints используемые:
- `GET /specialist-profiles/types` - список типов
- `GET /specialist-profiles/me` - получить профиль
- `PUT /specialist-profiles/me` - обновить профиль
- `POST /users/` - регистрация с specialist_type

### Переводы:
- Все переводы в `frontend/src/i18n/translations.ts`
- Типы переводятся через `getTranslatedSpecialistType()`
- Категории и бизнес-типы переводятся через `t()`

### Валидация:
- Frontend валидация для healthcare специалистов
- Backend валидация через Pydantic схемы
