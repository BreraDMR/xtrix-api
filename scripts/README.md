### Как запустить:

```powershell

# (вы должны видеть (venv) в начале строки)

python scripts/create_test_data.py
```

### После запуска:

1. Откройте браузер и перейдите на:
   - http://localhost:8000/docs - документация API (Swagger)
   - http://localhost:8000/api/v1/users/ - список пользователей (нужна авторизация)
   - http://localhost:8000/api/v1/clients/ - список клиентов (нужна авторизация)

2. Для просмотра данных через API:
   - Сначала авторизуйтесь через `/api/v1/users/login`
   - Используйте email и пароль из скрипта
   - Получите токен и используйте его в заголовке `Authorization: Bearer <token>`

### Примечание:

Скрипт проверяет, не существуют ли уже такие данные. Если пользователь или клиент уже есть, он не будет создан повторно.
