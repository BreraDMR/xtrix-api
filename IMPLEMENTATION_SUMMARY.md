## 🔧 Что было реализовано

### 1. Типы специалистов (25+ типов в 3 категориях)

**Beauty (Красота):**
- Массажист, Косметолог, Барбер, Парикмахер
- Эстетист, Маникюрщик, Мастер по ресницам/бровям, Визажист

**Wellness (Велнес):**
- Физиотерапевт, Нутрициолог, Ароматерапевт
- Фитнес-тренер, Инструктор йоги, Психолог, Психотерапевт

**Healthcare (Здравоохранение):**
- Терапевт, Стоматолог, Дерматолог, Врач-специалист
- Кардиолог, Невролог, Ортопед, Гинеколог, Уролог
- Офтальмолог, Эндокринолог, Педиатр, Хирург, Онколог

### 2. Расширенный профиль специалиста

Содержит:
- Тип и категория специалиста
- Специализация, опыт, образование, сертификаты
- Информация о бизнесе (название, тип, адрес)
- Языки, верификация

### 3. API Endpoints

```
POST   /specialist-profiles/              - Создать профиль
GET    /specialist-profiles/me            - Свой профиль
PUT    /specialist-profiles/me            - Обновить свой профиль
GET    /specialist-profiles/users/{id}    - Профиль по user_id
PUT    /specialist-profiles/users/{id}    - Обновить (admin)
GET    /specialist-profiles/              - Список с фильтрами
GET    /specialist-profiles/types         - Список типов
```

### 4. Переводы

Все переводы добавлены на 3 языка:
- Английский (EN)
- Русский (RU)
- Чешский (CZ)
