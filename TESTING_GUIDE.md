## 🧪 Тестирование

### 1. Тест Backend API

#### Запустить backend:
```bash
uvicorn app.main:app --reload
```

#### Запустить тестовый скрипт:
```bash
python scripts/test_specialist_types_api.py
```

Этот скрипт проверит:
- ✅ GET /specialist-profiles/types - список типов
- ✅ POST /users/ - создание пользователя с specialist_type
- ✅ POST /specialist-profiles/ - создание профиля
- ✅ GET /specialist-profiles/me - получение профиля

#### Или протестировать вручную через Swagger:
1. Открыть: http://localhost:8000/docs
2. Протестировать endpoints:
   - `GET /specialist-profiles/types` - получить список типов
   - `POST /users/` - создать пользователя со specialist_type="massage"
   - `POST /specialist-profiles/` - создать профиль
   - `GET /specialist-profiles/me` - получить свой профиль (нужна авторизация)

### 2. Тест Frontend

#### Запустить frontend:
```bash
cd frontend
npm run dev
```

#### Открыть в браузере:
http://localhost:3000

#### Проверить:
1. **Регистрация (`/register`):**
   - Выбрать role="specialist"
   - Должен появиться выбор типа специалиста
   - Выбрать тип (например, "Massage Therapist")
   - Зарегистрироваться
   - ✅ Проверить, что тип сохранился

2. **Профиль специалиста (`/profile`):**
   - Войти как специалист
   - Перейти в "Profile" (в меню навигации)
   - Просмотреть профиль
   - Нажать "Edit"
   - Заполнить дополнительные поля (опыт, образование и т.д.)
   - Сохранить
   - ✅ Проверить, что данные сохранились

3. **Создание клиента:**
   - Если специалист healthcare:
     - При создании клиента должно появиться предупреждение
     - Поля "Allergies" и "Chronic Diseases" должны быть обязательными
   - ✅ Проверить, что валидация работает

### 3. Проверка переводов

В форме регистрации и профиле проверить:
- ✅ Все тексты переводятся (EN/RU/CZ)
- ✅ Типы специалистов переводятся корректно
- ✅ Категории переводятся корректно
