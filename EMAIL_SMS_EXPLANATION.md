# Объяснение: Email и SMS для восстановления пароля

## Проблема с Mailgun Sandbox

**Mailgun Sandbox** (бесплатный тестовый домен) позволяет отправлять email **ТОЛЬКО на адреса, которые вы вручную добавили и подтвердили** в Mailgun Dashboard.

### Это значит:
- ❌ Нельзя отправить email на адрес нового пользователя автоматически
- ❌ Нужно вручную добавлять каждый email перед отправкой
- ✅ Подходит только для тестирования

## Решения для продакшена

### Вариант 1: Верифицировать свой домен в Mailgun (рекомендуется)

**Преимущества:**
- ✅ Можно отправлять на **любые** email адреса
- ✅ Нет ограничений на получателей
- ✅ Профессиональный вид (письма от вашего домена)

**Что нужно:**
1. Верифицировать свой домен в Mailgun (например, `xtrix.com`)
2. Настроить DNS записи (MX, TXT, CNAME) у вашего хостинга
3. После верификации можно отправлять на любые адреса

**Стоимость:**
- Первые 5,000 писем в месяц - бесплатно
- Далее ~$0.80 за 1,000 писем

### Вариант 2: Использовать другие сервисы

**Resend.com:**
- 3,000 писем/месяц бесплатно
- Можно отправлять на любые адреса
- Простая настройка API

**SendGrid:**
- 100 писем/день бесплатно
- Можно отправлять на любые адреса

**AWS SES:**
- 62,000 писем/месяц бесплатно (в рамках AWS Free Tier)
- Нужно выйти из sandbox режима

## SMS через Twilio

### Как это работает:

1. **Создайте аккаунт в Twilio**: https://www.twilio.com
2. **Получите:**
   - `TWILIO_SID` (Account SID)
   - `TWILIO_TOKEN` (Auth Token)
   - `TWILIO_FROM` (номер телефона для отправки)

3. **Добавьте переменные в Railway:**
   ```
   TWILIO_SID=ACxxxxxxxxxxxxx
   TWILIO_TOKEN=your_auth_token
   TWILIO_FROM=+1234567890  (номер от Twilio)
   ```

### Преимущества:
- ✅ Можно отправлять SMS на **любые** номера
- ✅ Работает в любых странах
- ✅ Не нужно ничего верифицировать заранее

### Стоимость:
- ~$0.0075 за SMS (зависит от страны)
- $1 за номер телефона для отправки
- Первые $15.50 бесплатно при регистрации

## Текущая реализация в коде

### Email восстановление пароля:

1. **Пользователь нажимает "Forgot password?"**
2. **Вводит email или телефон**
3. **Система:**
   - Генерирует 6-значный код
   - Сохраняет его в базе данных
   - Отправляет через Mailgun API (или SMTP)
   - Если Mailgun не настроен - логирует код в Railway

### SMS восстановление пароля:

1. **Пользователь вводит номер телефона**
2. **Система:**
   - Генерирует 6-значный код
   - Отправляет через Twilio API
   - Если Twilio не настроен - логирует код в Railway

## Рекомендации

### Для тестирования сейчас:
1. Добавьте свой email в Mailgun Authorized Recipients
2. Проверьте работу восстановления пароля
3. Код будет логироваться в Railway, если email/SMS не настроены

### Для продакшена:
1. **Верифицируйте свой домен в Mailgun** (чтобы отправлять на любые email)
2. **Настройте Twilio** (чтобы отправлять SMS на любые номера)
3. Добавьте все переменные в Railway

## Что будет, если не настроить?

Если Mailgun/Twilio не настроены:
- Код восстановления **логируется в Railway**
- Пользователь видит сообщение "Код отправлен"
- Вам нужно будет вручную посмотреть код в логах Railway
- Это **только для тестирования**, не для продакшена!
